# GreenIN AI — règles de marque et de transparence

**Nom visible officiel : GreenIN AI.**

Toutes les fonctions d'assistance à l'utilisateur de PitchStudio (analyse de documents, propositions, reformulation, boutons, chargements, statuts et erreurs) emploient GreenIN AI.

Les consentements doivent toutefois expliquer explicitement que les contenus transmis par l'utilisateur sont traités par OpenAI, fournisseur technique de GreenIN AI. Ne pas masquer cette destination.

Ne jamais renommer les contrats techniques historiques sans migration : OPENAI_API_KEY, AG24_PITCH_OPENAI_MODEL, apiPitchOpenAIHealth, OPENAI_CONSENT_REQUIRED, fournisseur OPENAI, API Responses, schémas et événements d'audit restent inchangés.

Le nom AfriGreen AI dans le connecteur existant désigne le système source et son identifiant canonique ; son contrat n'est pas modifié par la marque de l'assistant PitchStudio.

Test automatique : tests/greenin-ai-brand.test.cjs, exécuté par la CI aux côtés des tests fonctionnels.
